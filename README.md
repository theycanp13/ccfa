# ccfa：研究与写作方法

本仓库维护可复用的研究与写作思路。具体论文的题目、数据、实现、正文、实验结果和本机环境配置在各自工作区维护，不纳入此仓库。

当前发布的是已明确的**工具选择模块**：不固定模型、数值库、编程语言、绘图服务或文稿格式；先定义研究主张及证据需要，再选择并验证工具。

- [工具选择提示词](PROMPT.md)：供研究与写作助手使用。
- [选择原则与记录约定](methods/tool-selection.md)：模型角色、实现层次、安全假设、图表来源及输出格式。

方法文档中的实例路径是本地工作区的存储契约，不代表仓库包含这些研究文件。使用者在自己的研究工作区建立相应记录，并通过路径引用。当前仓库不提供自动运行引擎，也不宣称已实现所有工具适配。

通用方法规定过程、判断依据和交接位置；实际工具、参数、版本与结果只在所属实例或环境文件维护。同一个可变事实只维护一处，其他文件引用它。

最初讨论参考了开心猫在[知乎的回答](https://www.zhihu.com/question/2023500005038724243/answer/2023703161425143031)。本仓库收录的是适配后的方法模块，不是该回答全文或作者原始配置。
