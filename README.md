# ccfa：研究与写作方法

本仓库维护可复用的研究与写作思路。具体论文的题目、数据、实现、正文、实验结果和本机环境配置在各自工作区维护，不纳入此仓库。

从 [PROMPT.md](PROMPT.md) 开始阅读完整的当前审阅稿，包含通用工作方法、阶段路线和分阶段提示词。它以此前本地的分层版本为基础整合，不是原版逐字对照稿，也不表示原版中所有待讨论问题已解决。

- [完整提示词审阅稿](PROMPT.md)：总指引、阶段路线与分阶段指令。
- [选择原则与记录约定](methods/tool-selection.md)：模型角色、实现层次、安全假设、图表来源及输出格式。
- [安全证明、实际执行、修订与消融](methods/research-integrity.md)：本次确认的四项规则。
- [内容归属与存储约定](methods/storage.md)：通用方法、环境与具体论文如何引用而不混写。
- [改动记录](CHANGELOG.md)：本次改动范围及待审阅事项。

本次更新明确：安全证明需要单独审查；本研究实验结果必须来自实际执行的代码或流程，但不要求全部代码由自己编写；允许有依据地精简；消融按必要性和有效条件使用。其他新建议暂不扩展。

方法文档中的实例路径是本地工作区的存储契约，不代表仓库包含这些研究文件。使用者在自己的研究工作区建立相应记录，并通过路径引用。当前仓库不提供自动运行引擎，也不宣称已实现所有工具适配。

通用方法规定过程、判断依据和交接位置；实际工具、参数、版本与结果只在所属实例或环境文件维护。同一个可变事实只维护一处，其他文件引用它。
